# 快照版恢复说明

本仓库针对**官方 PCL 2.99.0.0 快照版（build 414）**这一个二进制文件，把官方因合规原因下线的 MC 下载与整合包安装恢复回来，同时关闭启动器云控与自更新。

- 输入：`input/official-snapshot.exe`
- 输入 SHA-256：`5b64d6d540c376390470cea3ab99d47661e8bca81be2ba647ea83e7d2e9428fa`
- 补丁工具：`tools/RestorePclKz`（Mono.Cecil），输入哈希不匹配会直接失败，不会静默套用到别的版本。

## 恢复了什么

| 位置 | 改动 |
|---|---|
| 下载页版本列表 | `PageDownloadInstall.LoaderInit` 恢复为加载 `DlClientListLoader`，不再使用"关闭下载"任务 |
| 导入整合包 | `ModModpack.ModpackInstall()` 恢复文件选择与后台线程（方法体取自 2.14 供体，成员按新模块重映射） |
| 整合包安装 | `ModModpack.ModpackInstall(File, …)` 恢复七路分派：CurseForge / HMCL / MMC / MCBBS / Modrinth / 带启动器的压缩包 / 未知压缩包；解析器与安装器沿用快照版原有实现 |
| 版本修改页 | 恢复"MC 版本"卡片显示 |
| 资源详情页 | 恢复 ModPack 的"安装"主操作与"保存"图标操作（其它资源类型仍只有保存） |
| 整合包导出 | 打包 PCL 时复制当前恢复版本地副本，不再下载官方最新版或复用官方 `Latest.exe` 缓存 |

## 关闭了什么

- 不获取、不回放 PCL 服务器的 `notice.cfg`、`notice.json`、`ServerConfig.json`（`ServerSub` 与相关回调被置空）。
- 不执行云端公告里的修改设置、结束程序、普通更新与静默更新动作。
- 关闭启动器更新下载、安装、退出时应用更新与 `--update` 替换 EXE 的入口（`UpdateStart` / `UpdateRestart` / `UpdateReplace` 置空）。
- "检查更新"按钮改为提示本恢复版已关闭启动器更新。

## 与正式版恢复版的差异

正式版补丁里有两处修改只删除**不可达**代码，本仓库**故意不做**，以减少锚点：

1. 拖入文件失败处理里针对"为遵守相关法律法规……"的特判 —— 恢复后该异常不再出现，分支不可达。
2. "关闭下载"任务的两个 lambda —— `LoaderInit` 恢复后不再构造该任务，不可达。

因此两个产物的行为一致，只是本仓库的改动面更小。

## 验证范围

Actions 中执行：

1. **输入校验**：官方快照版与 2.14 供体的 SHA-256 都必须匹配。
2. **ILVerify 对比**（`tools/verification/verify_binaries.py`）：同一引用集分别验证原始与补丁后程序集，拒绝新增错误、拒绝被修改方法报错。
3. **JIT 门槛**（`tools/verification/jitcheck.ps1`）：让 CLR 逐个编译补丁报告里的方法。ILVerify 只做验证，不检查方法头栈上限，也不检查"try 块不得落入处理器"这类导入器规则，因此存在"验证通过、一调用就 `InvalidProgramException`"的方法；这一步专门拦它。
4. **开窗冒烟**（`tools/verification/smoke.ps1`）：在干净目录启动补丁后的 EXE，等待标题窗口稳定 10 秒并截图。

这些检查能证明"IL 结构合法、CLR 接受、主窗口能起来"，**不能**替代人工验证：真实下载、各种整合包格式、登录、游戏启动与长期运行仍需自己试。

## 注意事项

- 补丁只对上面那个哈希成立；官方发新版本必须重做锚点分析。
- 恢复版不会自动升级，以后要更新只能手动替换程序；换回官方 EXE 会重新带回官方限制与云控。
- 官方快照版内置匿名遥测（腾讯 CLS，`Settings.vb` 中默认开启），本补丁**不修改**它；如需彻底关闭，请用源码编译版并清空遥测地址。
- 程序仍写入 `PCL` 注册表目录，与官方版共享设置；首次使用建议先备份原程序目录以便对照。
